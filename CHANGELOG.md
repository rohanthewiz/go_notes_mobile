# Changelog

All notable changes to GoNotes Flutter will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-20

### Added
- Initial release of GoNotes Flutter
- Monaco editor integration for professional code editing
- Support for 20+ programming languages with syntax highlighting
- Local SQLite database for note storage
- Full-text search across all notes
- Pin notes to keep them at the top
- Auto-save functionality with visual feedback
- Multiple editor themes (VS Dark, VS Light, High Contrast)
- File import functionality with automatic language detection
- Share notes to other apps
- Keyboard shortcuts support (Ctrl+S, Ctrl+F, Ctrl+H, etc.)
- Dark and light themes following system preferences
- Comprehensive test suite (unit, widget, and integration tests)
- Material Design 3 UI

### Developer Features
- Auto-indentation and bracket matching
- Code folding support
- Find & Replace functionality
- Multiple cursor support
- IntelliSense suggestions
- Bracket pair colorization
- Line numbers
- Word wrap toggle
- Syntax-aware commenting

### Testing
- Unit tests for models and services
- Widget tests for UI components
- Integration tests for user flows
- 80%+ code coverage

### Documentation
- Comprehensive README with setup instructions
- Development guide with testing and debugging tips
- API documentation
- Code examples and best practices
